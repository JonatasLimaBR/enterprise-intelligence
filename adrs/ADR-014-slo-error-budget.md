# ADR-014 — SLO e error budget como base operacional

- Status: Aceita

## Decisão

Serviços e produtos de dados podem declarar SLIs/SLOs e error budgets. Alertas priorizam burn rate e impacto, evitando thresholds estáticos isolados.

## Consequências

Alinhamento entre confiabilidade e entrega; requer definição de indicadores realmente percebidos pelo consumidor.
