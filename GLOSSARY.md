# Glossário

| Termo | Definição no produto |
|---|---|
| Asset | Qualquer recurso técnico, informacional ou de negócio catalogado. |
| Observation | Sinal bruto e imutável recebido de uma fonte. |
| Event | Observação normalizada com semântica temporal e origem. |
| Incident | Interrupção ou degradação não planejada. |
| Problem | Causa ou padrão recorrente que explica um ou mais incidentes. |
| Change | Alteração em código, configuração, dado, modelo, infraestrutura ou política. |
| Finding | Achado técnico ou de governança que requer avaliação. |
| Evidence | Fato verificável usado por regra ou hipótese. |
| Hypothesis | Explicação candidata, com confiança e evidências pró/contra. |
| Blast radius | Conjunto e criticidade dos dependentes potencialmente afetados. |
| Data contract | Acordo versionado sobre schema, qualidade, SLA e ownership. |
| Semantic metric | Métrica de negócio definida, versionada e governada. |
| Ontology | Tipos e relações empresariais com semântica explícita. |
| Knowledge graph | Instâncias e relações consultáveis baseadas na ontologia. |
| Groundedness | Grau em que uma resposta é sustentada por fontes fornecidas. |
| Provenance | Evidência rastreável sobre origem e transformações de um artefato. |
| Policy engine | Motor determinístico que avalia permissões, gates e obrigações. |
| Autonomy level | Limite de ação permitido para agentes e automações. |
| Golden signal | Métrica essencial de saúde operacional. |
| SLO | Objetivo mensurável de nível de serviço. |
| Error budget | Tolerância consumível a falhas dentro de um período. |
